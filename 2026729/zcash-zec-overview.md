# Zcash (ZEC) Overview

A comprehensive guide to Zcash: the privacy-focused cryptocurrency.

---

## What is Zcash?

**Zcash (ZEC)** is a privacy-focused cryptocurrency that uses advanced zero-knowledge proofs (zk-SNARKs) to enable fully encrypted transactions while maintaining blockchain security.

### Key Features

| Feature | Description |
|---------|-------------|
| **Privacy Technology** | zk-SNARKs (Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge) |
| **Transaction Types** | Transparent (like Bitcoin) OR Shielded (private) |
| **Maximum Supply** | 21 million ZEC (same as Bitcoin) |
| **Block Time** | 75 seconds |
| **Launch Date** | October 28, 2016 |
| **Founder** | Zooko Wilcox-O'Hearn |
| **Developer** | Electric Coin Company (ECC) |

---

## How Zcash Privacy Works

### Transparent vs. Shielded Transactions

```
TRANSPARENT (t-address)          SHIELDED (z-address)
─────────────────────────        ─────────────────────────
• Like Bitcoin                   • Fully encrypted
• Sender visible                 • Sender hidden
• Receiver visible               • Receiver hidden  
• Amount visible                 • Amount hidden
• On public blockchain           • Only proof of validity shown
```

### The Technology: zk-SNARKs

> Zero-knowledge proofs allow the network to verify that a transaction is valid **without revealing any sensitive information** — sender, recipient, or amount.

**Key benefit:** Zcash is **fungible** when coins are fully shielded, meaning tokens in the private pool have no traceable history.

## Zcash Halving Schedule

### What is a Halving?

A halving is a protocol-driven event that **reduces mining rewards by 50%**. This occurs approximately every 4 years (every 1,680,000 blocks).

### Halving History & Schedule

| Event | Block Height | Date | Block Reward |
|-------|--------------|------|--------------|
| **Launch** | 0 | Oct 28, 2016 | 12.5 ZEC |
| **Blossom Adjustment** | 653,600 | Dec 11, 2019 | 6.25 ZEC* |
| **1st Halving** | 1,046,400 | Nov 18, 2020 | 3.125 ZEC |
| **2nd Halving** | 2,726,400 | Nov 23, 2024 | 1.5625 ZEC |
| **3rd Halving** | 4,406,400 | ~Nov 2028 (est.) | 0.78125 ZEC |
| **4th Halving** | 6,086,400 | ~Nov 2032 (est.) | 0.390625 ZEC |
| **5th Halving** | — | ~2036 (est.) | 0.1953125 ZEC |

*The Blossom upgrade reduced block time from 150s to 75s, halving the reward to maintain the same issuance rate.

## Why Zcash Matters

### Use Cases

1. **Financial Privacy** — Protect transaction details from public view
2. **Business Confidentiality** — Hide competitive financial information
3. **Personal Security** — Prevent targeting based on wealth
4. **Selective Disclosure** — Option to reveal for audits/compliance
5. **Fungibility** — Shielded coins have no traceable history

### Saylor's View on Privacy

> "Privacy is a human right. Without privacy, there is no freedom."

While Michael Saylor focuses primarily on Bitcoin, the privacy thesis suggests that as surveillance increases, privacy-preserving technologies become more valuable.
